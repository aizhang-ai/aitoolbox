# 30 AI Prompts That Will Save You 10+ Hours Every Week **Last updated: September 2026** Most people use AI like a search engine — type a question, get an answer, move on. But the real power of AI lies in structured prompts that turn it into a specialized assistant for your exact workflow. Here are 30 prompts that genuinely save time. ## Why Most People Get AI Prompts Wrong The problem isn't the AI model. It's the prompt. A vague prompt like "write a blog post" gives you a generic, soulless article. A structured prompt with context, constraints, and desired output format gives you something useful. Every prompt below follows this framework: 1. **Role** — Who the AI should act as 2. **Task** — What specifically to do 3. **Context** — Background information 4. **Constraints** — What to avoid or limit 5. **Output format** — How the response should be structured ## Coding Prompts ### 1. Code Review Assistant ``` You are a senior software engineer doing a code review. Review the following code for: 1. Bugs and potential issues 2. Performance improvements 3. Security concerns 4. Code style and readability 5. Best practices for the language/framework Provide specific, actionable feedback with code examples where relevant. ``` This catches issues you'd miss in self-review. The "senior engineer" framing produces more thorough analysis than a generic "review my code" prompt. ### 2. Debug Helper ``` I'm getting this error: [ERROR] Here's my code: [CODE] Context: [WHAT YOU'RE TRYING TO DO] Help me: identify root cause, explain why, provide a fix, suggest prevention. ``` The prevention step is key — it turns a one-time fix into a learning moment. ### 3. Git Commit Message Writer ``` Write a git commit message following Conventional Commits format. Type: feat/fix/docs/style/refactor/test/chore/perf Subject line under 50 characters. Body explaining what and why. ``` Never stare at a blank commit message again. ### 4. Regex Generator ``` Generate a regular expression for: [DESCRIBE IN PLAIN ENGLISH] Provide: pattern, explanation, test cases, language-specific syntax. ``` Stop spending 30 minutes on regex. Describe what you want in English. ### 5. SQL Query Builder ``` Write a SQL query for: [DESCRIBE] Schema: [PASTE] Optimize for performance. Add comments. Include index recommendations. ``` ## Writing Prompts ### 6. Blog Post Generator ``` Write a 1500-2000 word blog post about [TOPIC]. SEO-optimized for [KEYWORD]. Include compelling title, meta description, H2/H3 headings, actionable takeaways, conversational tone, CTA. ``` ### 7. Email Writer Pro ``` Write a professional email. Purpose: [WHAT] Recipient: [WHO] Tone: [formal/friendly/urgent/apologetic] Key points: [LIST] Include subject line. End with specific CTA. ``` ### 8. Product Description Writer ``` Write product descriptions for [PRODUCT]. Include: short (50 words), full (200+ words), 5 bullet points, meta tags. Target audience: [DESCRIBE]. Tone: [DESCRIBE]. ``` ### 9. Press Release Generator ``` Write a press release for [ANNOUNCEMENT]. Include: headline, dateline, 2-3 paragraphs, quote, boilerplate, media contact. Under 500 words. ``` ### 10. Technical Documentation Writer ``` Write technical docs for [FEATURE/API]. Audience: [DEVELOPERS/USERS]. Include: overview, quick start, installation, config, usage examples, troubleshooting, FAQ. ``` ## Marketing Prompts ### 11. Landing Page Copywriter ``` Write landing page copy for [PRODUCT]. Include: headline, subheadline, 3 benefits, social proof, features, pricing, FAQ, CTA. Target audience: [DESCRIBE]. Tone: [DESCRIBE]. ``` ### 12. Social Media Content Calendar ``` Create a 30-day content calendar for [PLATFORM]. Niche: [DESCRIBE]. For each day: content type, topic, caption, hashtags, posting time. ``` ### 13. Ad Copy Generator ``` Write ad copy for [PRODUCT] on Google, Facebook, LinkedIn. 3 headline variations, 2 descriptions, CTA options, budget allocation. ``` ### 14. SEO Keyword Research ``` Generate SEO keywords for [TOPIC]. 20 primary, 10 long-tail, 5 question-based, content clusters, quick-wins. Include search intent for each. ``` ### 15. Email Sequence Builder ``` Create a 5-7 email [TYPE] sequence for [PRODUCT]. For each: number, purpose, subject (2 variations), preview text, body (300-500 words), CTA, timing. ``` ### 16. Brand Voice Guide ``` Create a brand voice guide for [BRAND]. Define: characteristics, vocabulary do's/don'ts, sample sentences, tone variations, complaint handling. ``` ## Analysis Prompts ### 17. Data Analysis Assistant ``` Analyze this data: [PASTE/DESCRIBE]. Provide: summary stats, trends, anomalies, correlations, recommendations, suggested visualizations. ``` ### 18. Competitor Analysis ``` Analyze competitors: [LIST]. For each: product comparison, pricing, target market, marketing channels, strengths/weaknesses, position. Provide strategic recommendation. ``` ### 19. SWOT Analysis ``` Conduct SWOT for [COMPANY/PROJECT]. 5 items per quadrant with evidence/impact. Strategic recommendations + 90-day action plan. ``` ### 20. Survey Designer ``` Design a survey for [GOAL]. 10-15 questions (mixed types), demographic questions, skip logic, analysis method per question. ``` ## Productivity Prompts ### 21. Daily Planner ``` Plan my day. Time: [NOW]. Hours available: [X]. Energy: [HIGH/MED/LOW]. Tasks: [LIST with priority and time]. Group similar tasks. Schedule high-energy tasks at peak. Include breaks. Leave buffer. ``` ### 22. Meeting Notes Summarizer ``` Structure these notes into: summary, key decisions, action items (with owner/deadline), open questions, next steps. Format as email to attendees. ``` ### 23. Project Breakdown ``` Break down [PROJECT] into tasks. Deadline: [DATE]. Team: [SIZE]. Budget: [AMOUNT]. For each: description, time, dependencies, skills, risk. Create timeline. Identify critical path. ``` ### 24. Decision Matrix ``` Help me decide: [DESCRIBE CHOICE]. Options: [LIST]. Priorities (weight 1-10): [LIST]. Create weighted matrix, score, recommend with reasoning. ``` ### 25. Learning Roadmap ``` Create a learning plan for [SKILL]. Current level: [LEVEL]. Time: [HOURS/WEEK]. Goal: [WHAT]. Deadline: [WHEN]. Week-by-week curriculum, free resources, practice projects, milestones. ``` ### 26. Habit Tracker System ``` Design a habit system for [HABIT]. Include: habit stacking, minimum viable habit, environment design, accountability, rewards, 30-day plan, failure recovery. ``` ## Advanced Prompts ### 27. Code Refactoring ``` Refactor this code for: readability, performance, maintainability. Don't change behavior. Explain each change. Before/after comparison. ``` ### 28. API Documentation from Code ``` Generate API docs from this code: Include: endpoints, methods, params, request/response schemas, examples, auth, error codes. Format as Markdown. ``` ### 29. Competitive Feature Matrix ``` Compare features across [PRODUCT] and [3-5 COMPETITORS]. Create a matrix with: feature name, which products have it, quality, gaps, opportunities. ``` ### 30. Retro Post-Mortem ``` Analyze this project outcome: [DESCRIBE]. What went well, what didn't, root causes, lessons learned, action items. Format for team sharing. ``` ## How to Customize These Prompts The prompts above are templates. Fill in the bracketed sections with your specific details.
