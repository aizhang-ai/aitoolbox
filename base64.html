Base64 Encoder / Decoder

Fast, client-side Base64 encoding and decoding. No data leaves your browser.

ℹ️ About Base64

Base64 is an encoding scheme that converts binary data into an ASCII string format. It's commonly used for encoding data in URLs, email attachments, and API payloads. This tool runs entirely in your browser — no data is sent to any server.
